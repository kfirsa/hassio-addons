# Images

This directory contains images and documentation assets for the Extended CUPS Print Server addon.

## ZJ-58 Thermal Printer

The ZJiang ZJ-58 thermal printer product image is stored here. This image can be used in:
- Addon documentation
- README files
- Marketing materials
- User guides

### Image Files

- **Primary File**: `zj-58-printer.jpg` (recommended for documentation)
  - Format: JPEG
  - Size: ~95KB
  - Dimensions: 640x640 pixels


### Image Details

- **ZJiang 58MM Thermal Receipt Printer** product image
- Shows the printer with receipt output
- Displays USB and Bluetooth connectivity options
- Includes compatibility information (Android, iOS, Windows)
- Shows cash drawer support
